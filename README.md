# 五线谱与简谱记谱器

当前上传版本：第 24 版（和弦独立音轨），2026-10-08。

浏览器记谱工具，支持独立的五线谱与简谱编辑器、多份谱子、多声部、歌词、和弦、合唱分组、调号、拍号、连音、力度、表情、反复和钢琴播放。无需服务器或安装依赖。

## 编辑器与谱子

Shift+Tab 或谱式按钮只切换编辑器，不转换谱子。两种编辑器各自保留内容，首次切换到另一种编辑器时显示空白谱子。“一键转…”才执行转换，原谱保留；转换结果与目标编辑器某份谱子内容相同则直接打开已有谱子，保留其标题和撤销记录，不再新增。比对实际音高、时值、歌词、声部、调号拍号速度及演奏符号，忽略内部编号、标题和录入位置；没有相同谱子时才增加转换副本。空白且未改动的目标谱可直接接收转换。转为简谱前列举不支持的琶音、滑音、踏板、拨奏、弓奏及其位置，选择“忽略并继续”仅从副本删除，或“放弃”保留原谱。

谱面右上角“打印”左侧的“谱子”按钮选择当前编辑器的谱子；PgUp／PgDn 循环切换。列表每行右侧垃圾桶图标可删除相应谱子，点击后询问是否确认。取消或 Esc 保留内容。删除当前谱子会切换到同类另一份；若为同类最后一份则显示新空白谱子。其他谱子和编辑器保留，删除结果自动保存。每份谱子的撤销和重做独立。“新建”和“打开”都新增谱子，保留原有进度。所有谱子自动保存在本浏览器，旧版单谱文件会迁移为其中一份谱子。

## 录入与选择

五线谱和简谱均可按 Alt 新增小节，长按连续新增；Shift+Alt 删除末尾小节，长按连续删除，至少保留一个。原“＋小节”按钮改为“小节数”输入框。输入总数后按 Enter 或离开输入框应用，Esc 取消输入；悬停后滚动滚轮也可调整。增加时在末尾追加空白小节，继承调号、拍号、速度和各声部谱号；减少时删除末尾小节，涉及内容时先确认，支持撤销恢复。数量与快捷键、撤销、重做和谱子切换同步。

五线谱 Tab 切换编辑和选择。编辑模式点击空白谱位输入；左键点击音符头改为同样时值的休止符，再点休止符还原原音符或和弦；右键删除音符或休止符。同一时点的其他谱位添加和弦，吸附范围为 6 个谱面像素。编辑模式 ←／→ 将最近输入单音的时值减半／加倍并用于后续输入，↑／↓ 无需选择即可将最近输入单音上移／下移一个谱位；和弦仅修改最近添加的那个音，支持撤销。空格输入四分音符 C4。鼠标悬停显示音高和落点。

简谱连续键入 1–7 输入音级、0 输入休止符，无需确认。默认沿用前一音符时值，填满后继续下个小节。Enter 将上一音符或所选音符延长一拍；Ctrl 多选或框选相邻同音音符，Enter 合并并精确相加时值。Shift+Enter 缩短一拍，剩余时值必须大于零；空格将所选音符重置为一拍，无选择时重置最近输入音符。↑／↓ 改所选八度，无选择时设置后续八度；←／→ 将所选音符时值减半／加倍；未选中时直接修改最近键入的音符或休止符，后续输入沿用修改后的时值。点击已有数字再输入数字，上下叠放表示合唱分组，支持同音叠放，每个叠放音可独立修改时值。点击空白处继续录入旋律。

选择模式点击已选对象可取消。和弦单击选单音、双击选全和弦；单音选中时，时值菜单、附点和 ←／→ 仅修改该音。Ctrl 多选、拖动框选、Ctrl 拖动追加，五线谱编辑模式开始框选后自动切换选择。↑／↓ 移动一个谱位（简谱为八度），A／D 调整音符先后顺序，鼠标拖动调整位置及音高。Ctrl+C／Ctrl+V 复制粘贴选中内容。Delete 删除，Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。Backspace 在无选择时删除最近输入的一个内容。和弦各音同时起音、按各自时值结束，后续音符保持原有起点，长音可在独立音轨中继续播放。

直接点击谱面左上角修改调号、拍号和速度；速度可输入任意正数（含小数），也可通过滚轮或原有按键调节，没有预设上下限，保存、打开和转换保留原值；五线谱另外支持谱号和调式，简谱移除这两个选项。修改后询问当前小节或之后所有小节，后者包含当前。声部独立录入，默认显示空白行，勾选“隐藏空白行”才隐藏。删除后默认名称按剩余顺序重新编号（声部 2 可变为声部 1），手动命名保留；重命名和声部删除在同一次撤销中恢复。已选音符或小节悬停约半秒出现分类菜单，离开后收起；键入时不自动弹出。

## 符号与排版

“⌒ 连线”自动判断：连续同音为延音线，不同音高为圆滑线。详细菜单仍可分别修改。添加范围符号时始终重新选起点，再选终点，也可从起点拖至终点。起点和终点提示放在谱面内，完成后自动回到选择模式，Esc 中途取消。拖动到窗口边缘时自动滚动。渐强渐弱线和 cresc.、dim. 独立添加；力度矛盾会提示并提供修正。

连音数量 2–32，可输入或滑条选择，总时值可自行设置；均分后能用普通或附点音符表示时不使用连音括号。两种谱式按 . 增加最近输入音符的附点，无预设数量限制，不改变下一音符的默认基础时值。短音符按拍连接符梁；未写满的小节保留后续输入空间，仅填满后整理。简谱延时横线按拍均匀分布，反复起点、终点固定在每行同一基线上，反复次数可自行输入。

简谱以四分拍为基准，下方每条横线将时值减半，右侧每条横线增加一拍，长休止使用多个 0；上、下点表示高、低八度；1=… 表示调号。转换保留实际音高、时值、声部和歌词，八度线折算为八度点。

## 播放与帮助

两种编辑器均用 P 播放／暂停，恢复时从暂停处继续；S 停止并归零。右上角按钮标明快捷键，播放中显示“暂停”。钢琴播放实际体现上下行琶音、跨谱表琶音、经过中间音高的滑音、倚音、颤音、波音、回音，以及断奏、顿音、重音、强重音、保持音、连奏、连断奏、换气、延长记号、延音线、圆滑线、踏板、渐强渐弱、八度和反复。初始力度为 mp，普通力度按声部延续，直到出现新标注；延续只影响播放，不自动添加谱面标记。力度档位使用更宽的音量范围（p 到 f 的振幅相差超过十倍），并随力度改变钢琴明亮度。渐强渐弱连续改变音量和明亮度，指定的终点力度优先；未标终点时默认移动两个等级，例如 p→mp→mf 或 f→mf→mp，结束后维持达到的力度。瞬时强音不会自动沿用到后续音符。pizz.／arco 保持钢琴音色，采用短促拨奏和缓起音连贯奏模拟；表情文字影响相应的力度、连贯度和起音。歌词不参与播放。

左上角高音谱号右侧“帮助”按类别展开，点击类别才显示详细条目，鼠标离开不会关闭；Esc 或点击外部空白处关闭。原来的使用说明入口已移除。

## 保存与发布

自动保存所有谱子；“导出”备份当前谱子的 .score.json，“打开”读入为新增谱子。桌面版和网页版可通过导出／打开交换，跨地址不会自动同步。打印及底部统计针对当前呈现的谱子。

把此目录全部 13 个文件上传到 GitHub 仓库根目录，尤其包含新增 notebook.js 和 performance.js。同名文件直接覆盖，不必先删除。Settings → Pages：Source 选 Deploy from a branch，Branch 选 main，目录选 /(root)，Save；完成后 Visit site 提供网址。[GitHub 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 边缘滚动与片段播放

2026-10-08 边缘滚动与片段播放：框选、范围符号拖动接近窗口边缘时持续滚动；谱面横向溢出时滚动谱面。滚动期间实时换算谱面坐标，松开、Esc、取消或窗口失焦停止。“部分播放”按钮或 Shift+P 依次选择起点、终点；终点包含所点音符，空白处选整小节边界。完成后 Shift+P 播放／暂停，悬停“部分播放”按钮可重选范围或恢复全曲。绿／橙色线在两种谱式中显示播放边界。播放只包含片段，保持多声部、反复、变速、力度、渐强渐弱、奏法、延音与踏板。各谱子独立自动保存播放范围；打印不显示试听标记。网页、离线文件和上传源码同步，手机版独立文件未改动。

## 和弦单音时值

2026-10-08 和弦单音时值更新：单击选择和弦中的一个音后，时值菜单、附点和左右方向键仅修改该音；双击选择完整和弦后可一起调整。编辑模式的最近音时值和附点快捷键追踪最近添加的和弦单音。简谱 Enter、Shift+Enter、空格也可独立调整所选叠放音。五线谱按各音的时值绘制符头、附点和符干，简谱独立绘制减时线与延长线；每个和弦音同时起音，分别按自己的时值结束，后续音符保持原有起点，长音可在独立音轨中继续播放。保存、撤销、音符／休止符还原、删除后单音提升、复制粘贴、拖动、谱式转换及部分播放均保留独立时值。原独立手机版不改动。

## 和弦独立音轨

2026-10-08 和弦独立音轨更新：修改和弦任一单音的时值只改变该音的持续时间，其他和弦音及所有后续音符的起点保持不变。较长音符可与后续音符重叠播放，并跨小节按相应速度继续保持。各音使用独立音频源和音量控制；歌曲总时长计入最后仍在保持的音，部分播放也包含从前一小节延续进来的长音。完整和弦一起调整时仍可改变整体节奏。保存、撤销、复制粘贴、单音删除及五线谱／简谱转换保留独立播放关系。电脑版网页版、离线版和上传源码同步，独立手机版未改动。
