# 五线谱与简谱记谱器

浏览器记谱工具，支持独立的五线谱与简谱编辑器、多份谱子、多声部、歌词、和弦、合唱分组、调号、拍号、连音、力度、表情、反复和钢琴播放。无需服务器或安装依赖。

## 编辑器与谱子

Shift+Tab 或谱式按钮只切换编辑器，不转换谱子。两种编辑器各自保留内容，首次切换到另一种编辑器时显示空白谱子。“一键转…”才执行转换，原谱保留；转换结果与目标编辑器某份谱子内容相同则直接打开已有谱子，保留其标题和撤销记录，不再新增。比对实际音高、时值、歌词、声部、调号拍号速度及演奏符号，忽略内部编号、标题和录入位置；没有相同谱子时才增加转换副本。空白且未改动的目标谱可直接接收转换。转为简谱前列举不支持的琶音、滑音、踏板、拨奏、弓奏及其位置，选择“忽略并继续”仅从副本删除，或“放弃”保留原谱。

谱面右上角“打印”左侧的“谱子”按钮选择当前编辑器的谱子；PgUp／PgDn 循环切换。列表每行右侧垃圾桶图标可删除相应谱子，点击后询问是否确认。取消或 Esc 保留内容。删除当前谱子会切换到同类另一份；若为同类最后一份则显示新空白谱子。其他谱子和编辑器保留，删除结果自动保存。每份谱子的撤销和重做独立。“新建”和“打开”都新增谱子，保留原有进度。所有谱子自动保存在本浏览器，旧版单谱文件会迁移为其中一份谱子。

## 录入与选择

五线谱 Tab 切换编辑和选择。编辑模式点击空白谱位输入；点击音符头改为同样时值休止符，再点休止符删除；同一时点的其他谱位添加和弦。编辑模式 ←／→ 将刚输入的音符时值减半／加倍并用于后续输入，空格输入四分音符 C4。原先工具栏时值按钮已移除。鼠标悬停显示音高和落点。

简谱连续键入 1–7 输入音级、0 输入休止符，无需确认。默认沿用前一音符时值，填满后继续下个小节。Enter 将上一音符或所选音符延长一拍；Ctrl 多选或框选相邻同音音符，Enter 合并并精确相加时值。Shift+Enter 缩短一拍，剩余时值必须大于零；空格将所选音符重置为一拍。↑／↓ 改所选八度，无选择时设置后续八度；←／→ 时值减半／加倍。点击已有数字再输入数字，上下叠放表示合唱分组，支持同音叠放。点击空白处继续录入旋律。

选择模式点击已选对象可取消。和弦单击选单音、双击选全和弦；Ctrl 多选、拖动框选、Ctrl 拖动追加，五线谱编辑模式开始框选后自动切换选择。↑／↓ 移动一个谱位（简谱为八度）。Delete 删除，Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。叠放和弦共享时值。

直接点击谱面左上角修改调号、拍号和速度；速度可输入任意正数（含小数），没有预设上下限，保存、打开和转换保留原值；五线谱另外支持谱号和调式，简谱移除这两个选项。修改后询问当前小节或之后所有小节，后者包含当前。声部独立录入，整行空白声部隐藏，选中声部后展开。删除后默认名称按剩余顺序重新编号（声部 2 可变为声部 1），手动命名保留；重命名和声部删除在同一次撤销中恢复。已选音符或小节悬停约半秒出现分类菜单，离开后收起；键入时不自动弹出。

## 符号与排版

“⌒ 连线”自动判断：连续同音为延音线，不同音高为圆滑线。详细菜单仍可分别修改。范围符号可多选后直接应用，或先点工具再点起点、终点，也可从起点拖至终点。起点和终点提示放在谱面内，完成后自动回到选择模式，Esc 中途取消。渐强渐弱线和 cresc.、dim. 独立添加；力度矛盾会提示并提供修正。

连音数量 2–32，可输入或滑条选择，总时值可自行设置；均分后能用普通或附点音符表示时不使用连音括号。附点支持单、复、三附点。短音符按拍连接符梁；小节填满、切换或退出编辑后自动排布。简谱延时横线按拍均匀分布，反复起点、终点固定在每行同一基线上。

简谱以四分拍为基准，下方每条横线将时值减半，右侧每条横线增加一拍，长休止使用多个 0；上、下点表示高、低八度；1=… 表示调号。转换保留实际音高、时值、声部和歌词，八度线折算为八度点。

## 播放与帮助

两种编辑器均用 P 播放／暂停，恢复时从暂停处继续；S 停止并归零。右上角按钮标明快捷键，播放中显示“暂停”。钢琴播放实际体现上下行琶音、跨谱表琶音、经过中间音高的滑音、倚音、颤音、波音、回音，以及断奏、顿音、重音、强重音、保持音、连奏、连断奏、换气、延长记号、延音线、圆滑线、踏板、渐强渐弱、八度和反复。力度档位使用更宽的音量范围（p 到 f 的振幅相差五倍），并随力度改变钢琴明亮度。渐强渐弱连续改变音量和明亮度，指定的终点力度优先；未标终点时自动变化更明显。瞬时强音不会自动沿用到后续音符。pizz.／arco 保持钢琴音色，采用短促拨奏和缓起音连贯奏模拟；表情文字影响相应的力度、连贯度和起音。歌词不参与播放。

左上角高音谱号右侧“帮助”按类别展开，点击类别才显示详细条目，鼠标离开不会关闭；Esc 或点击外部空白处关闭。原来的使用说明入口已移除。

## 保存与发布

自动保存所有谱子；“导出”备份当前谱子的 .score.json，“打开”读入为新增谱子。桌面版和网页版可通过导出／打开交换，跨地址不会自动同步。打印及底部统计针对当前呈现的谱子。

把此目录全部 13 个文件上传到 GitHub 仓库根目录，尤其包含新增 notebook.js 和 performance.js。同名文件直接覆盖，不必先删除。Settings → Pages：Source 选 Deploy from a branch，Branch 选 main，目录选 /(root)，Save；完成后 Visit site 提供网址。[GitHub 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 文件与参考

- core.js：音乐数据、验证、时值、路线、力度包络。
- performance.js：奏法、琶音、滑音、装饰音的钢琴演奏调度。
- notebook.js：独立编辑器、多谱子、自动保存、分类帮助。
- jianpu.js：简谱绘制、数字输入、快捷键、转换。
- app.js：五线谱绘制、共享交互和音频播放／暂停。
- index.html、style.css：页面和样式。
- samples.js：嵌入钢琴采样，离线可播放。
- test-core.cjs：Node.js 核心测试。
